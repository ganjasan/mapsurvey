What changes against today

  • Half and half. Photo left, page right, like every other page; no 420-px respondent panel, no hidden map behind the photo, no Map toggle.
  • The right side reads like the paper. Map in the printed frame (one button returns to it), then the marks table with the same rows (A1…An) and the same columns as the printed table, then the page's other questions. The operator's eye goes photo → screen row by row.
  • Marks are rows. Each row is one mark: label, placed / no mark, the sub-answers as inputs, Show (photo scrolls to the mark and outlines it — the form-leads rule), ✕. A row the reader doubted is amber. A row the paper left empty is grey and offers "place it on the map" for a mark the reader missed; "+ Add a mark" does the same beyond the printed rows.
  • Drag a pin to correct a place; its row stays selected. Clicking a pin selects its row. The pop-up with sub-questions is not used here — the table is the pop-up.
  • Lines and areas are rows too: the shape is drawn on the map, its vertices draggable; the row's "On the map" says line · 4 points / area.
  • Saving is the same section POST: features from the map + the row inputs become the features' properties. Nothing new in storage.
  • Old flow stays for typing. The operator entry form without photos (item 1) keeps the respondent panel and its pop-ups; this layout is only the photo check.

Подсчёт белок — наблюдения

Отметьте на карте каждое животное, которое видите. Ваша зона выделена на карте.

Отмечено: 3 · Тапните по карте, чтобы добавить
Оверлей: зоны залиты цветом слоя (#e8971e, 15% opacity), подписи из поля «name». Тумблер слоя — в контроле справа сверху. Клики по зонам «прозрачны»: тап ставит точку наблюдения, зону выбрать нельзя.

Обновление парка

Перед вами проект обновления. Тапните по элементу плана, чтобы узнать, что запланировано, и оставьте свои предложения точкой на карте.

Поставьте точку и опишите идею
Оверлей: план в собственных цветах (simplestyle из GeoJSON: fill/stroke на фичах). Инфо-попапы включены — тап по «Детской площадке» открывает описание, но геометрию плана менять нельзя.

Объекты на карте — редактор (#151 + #152)

Ни одного нового экрана. Три существующих места расширяются (новое обведено пунктиром): 1) карточка «Reference layers» в настройках опроса — к слою добавляются слоты карточки объекта (title / category / image / description / link — все из свойств GeoJSON, дропдауны уже есть для label/key); 2) модалка вопроса — новый тип «Objects on the map» в группе Map questions, форма = существующие поля + слой + вложенные вопросы к объекту (паттерн «Choices»); 3) список вопросов секции — обычный question-item с бейджами, вложенные вопросы отступом как гео-подвопросы; preview справа показывает то, что видит респондент.

1 · Survey settings → Reference layers — существующая карточка слоя, раскрыта; ниже новый подраздел «Object cards»

1b · ЗАМЕЩЁН решением D9 (отдельный экран — см. layer-editor.mockup.html). Оставлен как история: таблица объектов внутри карточки слоя

Тело слоя (`.ref-layer-body`) получает два таба: Settings (то, что в п. 1) и Objects · 10 (новое). Таблица предзаполнена свойствами GeoJSON по маппингу из п. 1; дальше это источник истины — правки живут в записи объекта, не в файле. Строка раскрывается в редактор карточки: заголовок, категория, ссылка, Quill-описание (с той же кнопкой картинки, что на Thanks page) и вложения — изображения, аудио, документы, видео (файл с лимитом или embed-ссылка). Справа — живой предпросмотр карточки, как её увидит респондент в попапе (вариант A).

4 · Что сознательно НЕ добавляется

• Никакого редактора объектов внутри Mapsurvey (A2 из user stories): контент карточки берётся из свойств GeoJSON; правки — в файле и повторной загрузке. Появится, только если реальные создатели упрутся.
• Никакого отдельного экрана «слои» — карточка Reference layers в настройках остаётся единственным местом, где живёт слой.
• Никакого нового UI вложенности — вопросы к объекту в списке секции показываются с тем же отступом, что подвопросы гео-попапа. Как они хранятся — открытый вопрос №2 в user-stories.md (бэклог #152 запрещает моделировать их как sub-answer гео-ответа).

The 4-row desktop toolbar collapses into one bar: back · title · version chip · ⋯ overflow.

Decisions this mockup encodes (for design.md)

  • Two navigation levels, both contextual. Top strip = today's page tabs (Survey · Responses · Public results). Bottom tab bar = panes of the active page: Survey → Structure/Edit/Preview, Responses → Table/Map/Charts/Performance, Public results → Structure/Edit/Preview. Desktop layout stays untouched.
  • One pane vocabulary. Survey and Public results both use Structure / Edit / Preview — list of ordered things, editor of the selected thing, live result. Learned once, applied twice.
  • Drill-down inside Structure: sections list → section's questions → question opens in Edit. Two levels, breadcrumb back, no nested scrolling.
  • Reorder by long-press drag on the ⠿ handle only — no ▲▼ button clutter (review decision, v2).
  • Autosave replaces the Save button — on desktop too (review decision, v2): "● All changes saved" line, no sticky save control fighting the keyboard.
  • New question = full-screen type picker grouped with map types as a first-class indigo group; picking a type creates the question and opens Edit.
  • One-row header + ⋯ overflow absorbs Share / Settings / Versions / Publish / account (today: 4 wrapped rows).
  • Preview = real respondent page, which adopts the bottom-sheet map pattern (also fixes audit P1 findings #5–#8).
  • Responses on mobile leads with Charts; Table becomes per-session cards; the full data grid remains desktop-only in the first iteration.

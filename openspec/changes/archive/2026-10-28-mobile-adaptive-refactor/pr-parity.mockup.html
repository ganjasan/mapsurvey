Одна анатомия для двух вкладок

Public results структурно повторяет Survey: пользователь задаёт структуру, редактирует элемент, смотрит живое превью, публикует, замораживает/обновляет версию. Значит и интерфейс обязан быть одним: чип состояния (цветной) → статус-строка с primary-действием по состоянию → три панели Structure / Edit / Preview. Ниже — маппинг и два десктоп-кадра, различающиеся только содержимым, не формой.

AЧипы состояния цветные и единые: серый «не активен» (Draft / Not published), янтарный «ограниченный доступ» (Testing), зелёный «живой» (Open / Live), голубой «заморожен» (Frozen · дата). Чип PR — тоже меню: Publish/Unpublish/Freeze/Unfreeze, как чип Survey несёт lifecycle. Чип уходит из навбара в статус-строку своей вкладки — он описывает сущность вкладки (опрос ↔ публичная страница), а навбар общий для всех трёх вкладок, поэтому там чип статуса опроса вводил бы в заблуждение на вкладке Public results. В навбаре вместо него — цветные точки на самих табах: статус обеих сущностей виден с любой вкладки одним взглядом.
BShare у PR копирует /r/-ссылку (существующий prCopyPublicLink) — тот же смысл, что Share опроса: «дай людям адрес». «↗ Open as visitor» зеркалит «Open as respondent». Freeze — второе по важности действие живой страницы (снимок перед публичным анонсом), поэтому в строке, а не в ⋯; Unpublish — деструктив, в ⋯.
CМобильный вид наследуется автоматически: statusbar уже общий компонент, нижний бар Structure/Edit/Preview у PR уже есть. Отдельные мобильные кадры не нужны — они получаются из этих же строк тем же CSS, что у Survey.

Решения (в design.md)

  • Один скелет: чип состояния → статус-строка → Structure/Edit/Preview — идентичен на обеих вкладках и на всех ширинах.
  • Цветовая семантика чипов: grey=неактивен, amber=ограниченный доступ, green=живой, sky=заморожен. Применяется и к чипу Survey (сейчас он всегда серый), и к новому чипу PR.
  • Статусы PR: Not published (primary: Publish page; disabled с подсказкой, пока опрос-черновик) · Live (primary: Share; рядом Freeze) · Frozen (primary: Update snapshot; рядом Unfreeze в чипе/⋯).
  • Разбросанные контролы старого pr-ctxbar (Preview private / Copy link / Live page / Unpublish) и зелёный баннер уезжают в статус-строку и ⋯; сам бар остаётся только при выключенном флаге.
  • Блоки в Structure получают тип-бейдж (гео/chart/text) — аналог счётчиков вопросов у секций.

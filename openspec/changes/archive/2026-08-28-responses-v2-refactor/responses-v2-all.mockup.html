Responses v2 — одна система, три форм-фактора

Единая архитектура: плоская линейка панелей Overview · Map · Responses · Charts · Performance, постоянная KPI-полоса с дельтами, глобальные фильтры-пилюли, drawer вместо модалки. Форм-факторы сворачивают её прогрессивно: десктоп — всё сразу + split; планшет — то же без split, drawer поверх; телефон — Charts растворяется в Overview, панели в нижнем баре. Данные — citypulse.

Десктоп ≥1200px (кадры 1440×880, масштаб 74%)

Overview — новый дефолт (D1): отвечает «как идёт опрос» без единого клика. Данные и Performance больше не спорят: KPI-полоса одна на все панели, у Performance — явная пометка «tracked visits» (D2). Split view — явная кнопка, а не серые иконки (D5). Клик по строке таблицы открывает drawer с prev/next (D8).

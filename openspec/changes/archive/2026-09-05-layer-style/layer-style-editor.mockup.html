Reference layer style — base + one rule by attribute

Case: Sarasota/Manatee MPO loaded 6 119 road segments with priority_score / priority_class and had to split them into four layers because a layer has one colour. Proposal: every layer keeps a base style (colour, opacity, line width, point size, icon) and may add one rule — categories or graduated — on one object property. Priority at render: rule → simplestyle in the file → base. Respondents get a legend under the layer name in the layers control.

Shared map — respondents see and react to each other's marks (#160)

Julian Thomas (Whitehouse CC): «see previous submissions and up vote them instead of adding a new pin». Built on the merged overlay-features model: a reference layer with source = answers to a geo question, whose objects are materialised from respondents' marks; reactions are sub-questions of an ordinary Objects on the map question bound to that layer. Decisions so far: live by default + per-item hide, «approve first» as a layer option; tallies shown (option, on); others' comments (option, off); own marks excluded from the layer for the author; assembled by hand — a layer from answers plus an ordinary Objects question, no toggle.

# Каналы для целевой аудитории Mapsurvey (Urban Planners, Civic Tech, Municipal Government)

## 1. Ключевые сообщества по приоритету

### **PPGIS.net / DGroups** ⭐⭐⭐⭐⭐
- **URL:** ppgis.net, dgroups.org/groups/ppgis
- **Аудитория:** Глобальный электронный форум практиков Participatory GIS
- **Языки:** Английский, французский, испанский, португальский
- **Почему важно:** Это **самая целевая аудитория** для Mapsurvey. Участники — именно те практики, которые сейчас покупают Maptionnaire за $3000/год. На ResearchGate годами идут обсуждения с просьбами найти open-source PPGIS альтернативы.

### **IAP2 — International Association for Public Participation** ⭐⭐⭐⭐⭐
- **URL:** iap2.org, iap2usa.org
- **Аудитория:** 2,500+ членов в США, филиалы в 26+ странах
- **Формат:** Конференции, Knowledge Network, Communities of Practice
- **Почему важно:** Это профессионалы, которые организуют публичное участие и покупают инструменты типа Maptionnaire. Прямая целевая аудитория.

### **Planetizen** ⭐⭐⭐⭐⭐
- **URL:** planetizen.com
- **Аудитория:** Заявляют о **90% охвате урбанистического сообщества США**
- **Формат:** Новости, op-ed статьи, newsletter (200K+ подписчиков)
- **Действие:** Написать op-ed "Open-source alternatives for community engagement in planning"

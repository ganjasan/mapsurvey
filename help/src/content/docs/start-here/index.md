This tutorial takes you from an empty editor to a published survey and a first export. It is written for someone who has never used Mapsurvey; if you already have a survey running, the [how-to guides](/how-to/) answer single questions faster.

## What you will do

1. Choose how to start, create an empty survey and set up its map.
2. Add a map question with sub-questions, so every pin carries an answer.
3. Publish the survey and share the link.
4. Read the responses and export them for GIS.

## Before you start

- A Mapsurvey account. Sign up at [mapsurvey.org](https://mapsurvey.org/) — the free tier has no limits on surveys or responses.
- A question you want to ask about places. "Where do you feel unsafe crossing the street?" is the example used throughout, in a survey called "Safe crossings".

Start with [Create a survey](/start-here/create-a-survey/). Each page ends with a link to the next one; the whole path takes about an hour.

You end up with a printable PDF of your survey: every question with boxes and lines, the map of each page with your reference layers, and a code on every sheet so the answers can be matched back to this survey.

## Before you start

- You have the **editor** role or higher on the survey.
- The survey has the questions and pages you want on paper. The form is built from the survey as it is when you download it, so finish editing first.
- For a map page, set the page's start position and zoom on **Build → page settings → map**. The printed map shows exactly that view.

## Steps

1. Open the survey's **Share** page and find **Print a paper form** at the bottom.
2. Pick the **language** (one form per language) and the **paper size**, A4 or US Letter.
3. Press **Download PDF**. A draft survey prints with a DRAFT watermark, which is fine for proofing; publish it before handing sheets out.
4. Print the PDF at 100 % scale, in colour or black and white. Do not fit to page: the four black squares in the corners must stay 8 mm from the edges.

## What is on the form

- **Questions** in the order respondents see them, with the help text. Choices are boxes, text answers are lines, ratings and scales are numbered boxes. A question that respondents see only after a certain answer carries an "Answer only if …" line. Questions set to **Operators only** under *Who sees this* are left off.
- **The map** of every map page, with your reference layers drawn on it and a scale bar. Under it, a legend gives each map question a letter: **A ●** for a point, **B ━** for a line, **C ▭** for an area. The respondent draws the symbol on the map and writes the letter next to it. The follow-up questions of a map question are a small table with a row per mark (A1, A2, …).
- **A code on every page**, as text (`MS-7K-3`) and as a QR code. It names this printed form and the page, so a photographed sheet can later be matched to the right survey version and map. Keep the sheets whole; a page without its code cannot be matched.
- **On page 1**, a QR code with the survey's online link for people who would rather answer on a phone, and an "Office use" box for the sheet number you give each filled sheet.

## After the event

Type the filled sheets in with **Enter a response** on the Responses page, which is part of Pro: see [Enter responses for others](/how-to/enter-responses-for-others/). Write the sheet number from the office-use box into the operator-only "Sheet number" question if you added one.

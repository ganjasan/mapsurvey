If you collected or analysed data with Mapsurvey, please cite it. A citation lets readers find the tool and repeat your method, and it is how a free, open-source project shows funders that it is used in research.

## Reference

| Style | Reference |
|---|---|
| APA 7 | Koniukhov, A. (2026). *Mapsurvey* [Computer software]. https://mapsurvey.org |
| Harvard | Koniukhov, A. (2026) *Mapsurvey* [Computer software]. Available at: https://mapsurvey.org |
| Chicago | Koniukhov, Artem. 2026. *Mapsurvey*. Computer software. https://mapsurvey.org. |

Use the year in which you collected your data.

```bibtex
@software{koniukhov_mapsurvey,
  author  = {Koniukhov, Artem},
  title   = {Mapsurvey},
  year    = {2026},
  url     = {https://mapsurvey.org},
  license = {AGPL-3.0-only},
  note    = {Open-source participatory mapping survey platform. Source code: https://github.com/ganjasan/mapsurvey}
}
```

The same reference is in [`CITATION.cff`](https://github.com/ganjasan/mapsurvey/blob/master/CITATION.cff) in the source repository: GitHub's **Cite this repository** button turns it into APA and BibTeX, and reference managers such as Zotero read it.

## In the methods section

A sentence like this one is enough:

> Data were collected with Mapsurvey (Koniukhov, 2026), an open-source platform for participatory mapping surveys (https://mapsurvey.org).

Readers who want to repeat the study also need to know what respondents saw. It helps to name the question types you used (see [Question types](/reference/question-types/)), the base map, and whether answers outside the study area were refused (see [Survey settings](/reference/survey-settings/)).

## Academic Pro

Students, researchers and non-profit research projects can use [Pro](/reference/plans-and-billing/) free of charge. In return we ask for two things: feedback while you build and run the survey, and a citation of Mapsurvey in the publications that use its data.

To ask for it, write to [konuchovartem@mapsurvey.org](mailto:konuchovartem@mapsurvey.org) with a line about your study and the name of your Mapsurvey workspace.

When your paper is out, send us the link: we would like to read it.

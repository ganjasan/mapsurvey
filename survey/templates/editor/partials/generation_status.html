{% comment %} Polled while a draft is being generated. Rendered as a fixed overlay rather than inline in the form: generation takes up to a minute and the creator must not miss that it started, nor keep editing a form whose values are already on their way to the model. Inline it also sat below the fold on a laptop, which is exactly the confusion this replaces. The quips are entertainment, not telemetry: generation is a single opaque model call, so there is no honest per-step progress to show. Loading-screen flavour text is the established way to make a minute-long wait feel intentional rather than broken — it must never imply a pipeline stage the backend does not actually have. {% endcomment %}
{% comment %} The poller is a separate, empty element with hx-swap="none": while the draft is pending the endpoint answers 204 and nothing in the DOM changes. Polling the overlay itself (and swapping it whole every 2s) restarted the fade-in and the spinner on every tick, which read as the screen flickering. {% endcomment %}

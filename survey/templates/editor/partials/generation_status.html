{% comment %} Polled while a draft is being generated. Rendered as a fixed overlay rather than inline in the form: generation takes up to a minute and the creator must not miss that it started, nor keep editing a form whose values are already on their way to the model. Inline it also sat below the fold on a laptop, which is exactly the confusion this replaces. The quips are entertainment, not telemetry, and they stay that way. What changed is that the call now streams, so alongside them there IS an honest number: the `gen-progress` line below counts sections the model has actually finished writing, swapped in out-of-band by the poller (see generation_progress.html). The rule that produced this comment is unchanged and still binding — flavour text must never imply a pipeline stage the backend does not have. The quips cover the opening stretch, where the model is reasoning and the honest count is zero; showing "0 sections" there would read as a stall, so the line is absent until the first section closes. {% endcomment %}

Polling the overlay itself (and swapping it whole every 2s) restarted the fade-in and the spinner on every tick, which read as the screen flickering. {% endcomment %}

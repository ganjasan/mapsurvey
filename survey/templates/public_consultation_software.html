{% trans "What it is" %}

{% trans "What map-based consultation software does differently" %}

{% trans "Public consultation software is the tool a council, a planning authority, a transport agency or a developer uses to publish a proposal, collect responses and account for them in a report. The established products grew out of the document: you upload the consultation paper, add a questionnaire, open a window, close it, and export a spreadsheet of answers. That shape fits a policy consultation. It fits a spatial scheme badly, because the thing people want to talk about is a place, and the questionnaire has no idea where it is." %}

{% trans "An online public consultation platform built on a map starts from the drawing. You upload the scheme as a layer: the new route, the site boundary, the junctions, the trees to be removed. Each feature carries its own questions. Residents open the link, find the part of the plan that affects them, and respond right there: support or object, say why, add a photo. They can also mark places the plan missed, as a point, a line or an outlined area. Every response arrives with coordinates and the feature it refers to, so the analysis is a map and a count, not a reading exercise." %}

{% trans "Council consultation software has to produce a defensible record. Mapsurvey exports every response, including the geometry, as GeoJSON, CSV, Excel, GeoPackage, Shapefile or KML, so the GIS team and the report author work from one file. Individual free-text responses stay in the export; the public results page shows aggregated counts and maps only, with small groups masked, so a consultation can be transparent without publishing anyone's words. The survey can be versioned, so a second round after a design change keeps the first round's data intact." %}

{% trans "Mapsurvey is open source (AGPLv3). The hosted service runs in the United States; a council that needs its respondents' data on its own servers runs the same Docker stack in-house at no licence cost. Pricing is published on this page. There is no per-consultation fee, so a planning department can run every consultation of the year on one workspace." %}

{% comment %} Drag-to-order list. Each row carries a hidden input under the question's field name, so the submitted order IS the DOM order — moving a row moves its input, and getlist() reads the ranking back with nothing to parse. Without JavaScript the rows do not move and the question stays unanswered, which is the same trade-off the map questions make. The alternative — typed rank boxes — is the tie problem this question type exists to remove. {% endcomment %}

Drag the items into order, or pick one up with Space and move it with the arrow keys.

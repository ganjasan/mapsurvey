--- title: Personal access tokens kind: new link: editor_account_connections ---

Your account now has an API & connections page. Create a personal access token there — with the permissions you choose, for one workspace or all, with or without an expiry — and use it from a script, a GIS tool or an AI agent with Authorization: Bearer …. Revoke it with one click.

What it opens. The first endpoint, /api/v1/me, is live today; the REST API and the MCP server that these tokens unlock are next. The API is a Pro feature: tokens work on any plan, calls on a survey need its workspace on Pro.

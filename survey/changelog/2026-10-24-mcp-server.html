--- title: Build surveys and read responses from your own AI agent kind: new link: editor_survey_start_agent ---

Mapsurvey now has an MCP server. Connect Claude, ChatGPT, Claude Code, Cursor or any agent that speaks the Model Context Protocol, and ask it in plain words: "create a survey in German and English about where benches are missing, with a point question and an urgency rating". It hands you the link, a QR code for a poster and campaign links to send it out. Once answers come in, ask it to summarise them, read the comments, map what people drew, or give you an Excel file. It sees only your surveys, works through the same rules as the editor, and asks you before it publishes or deletes anything.

How to connect. Every assistant signs you in — no token to copy; scripts can use a personal token made for the MCP server. New survey → Use your AI assistant has the steps for each one, and the help centre has the set-up guide and every tool. The MCP server is a Pro feature: tools on a survey need its workspace on Pro.

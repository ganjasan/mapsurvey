--- title: Build surveys from your own AI agent kind: new link: editor_account_connections ---

Mapsurvey now has an MCP server. Connect Claude, ChatGPT, Claude Code, Cursor or any agent that speaks the Model Context Protocol, and ask it in plain words: "create a survey in German and English about where benches are missing, with a point question and an urgency rating". It sees only your surveys, works through the same rules as the editor, and asks you before it publishes or deletes anything.

How to connect. claude.ai and ChatGPT sign you in — no token to copy. Claude Desktop and Cursor take a personal token made for the MCP server. The address and the commands are on API & connections; the help centre has the set-up guide and every tool. The MCP server is a Pro feature: tools on a survey need its workspace on Pro.

--- title: The REST API kind: new link: editor_account_connections ---

Your personal access tokens now open the whole REST API: create a survey, add sections and questions, publish it, and read or export its responses from a script, a reporting pipeline, a QGIS workflow or your own app. It follows the same rules as the editor — wording on a live survey changes in place, structure goes through unpublished changes, and a token never does more than you could in the browser.

Where to start. The help centre has a step-by-step guide and a reference of every endpoint; the machine-readable contract is /api/v1/openapi.json. The API is a Pro feature: calls on a survey need its workspace on Pro.
